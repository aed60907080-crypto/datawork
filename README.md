# سجل صيانة الأجهزة — وزارة الأشغال العامة

نظام لتسجيل صيانة الأجهزة ومتابعتها في **المركز الحكومي**، يعمل كتطبيق على الهاتف والحاسب.

## التشغيل

**التطبيق (GitHub Pages):** https://aed60907080-crypto.github.io/datawork/
— البيانات تُحفظ على الجهاز نفسه، إلى أن يُربط بـ Firebase (انظر أدناه) فتصبح مشتركة.

**نسخة claude.ai (بيانات مشتركة بين كل المستخدمين):** https://claude.ai/artifact/77xEND12PeCtC2XESgzGGJ

عند أول فتح تظهر شاشة **الضبط الأول** لاختيار كلمات سر الجهات.

## التثبيت كتطبيق

- **أندرويد / Chrome / Edge على الحاسب:** افتح الرابط ثم اضغط زر **«تثبيت التطبيق»** في الشريط العلوي (أو من قائمة المتصفح ← تثبيت التطبيق).
- **آيفون / آيباد (Safari):** افتح الرابط ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

يفتح التطبيق في نافذة مستقلة بأيقونته، وعلى الهاتف تظهر الأقسام كشريط تبويبات سفلي.
يُحمَّل حتى مع ضعف الاتصال، وتصله التحديثات تلقائياً عند توفر الإنترنت.

## المزايا

- أوامر الصيانة: الموظف، القطاع، القسم، الطابق، الجهاز، الموديل، السيريال، التاغ، الفني، نوع الصيانة، الملاحظات
- تصوير رقم السيريال أو التاغ بالكاميرا
- مخزن قطع الغيار مع حركات الإدخال والصرف
- الفنيون وسجل كل فني
- لوحة متابعة ورسوم بيانية
- **بدل الموقع:** خريطة مواقع العمل، ومواقع الأقسام، والتقاط GPS
- التقارير الشهرية مرتّبة ومرقّمة، وتُرسل تلقائياً إلى رئيس الفريق بعد نهاية الشهر
- التصدير إلى Excel بملفات `.xlsx` منسّقة

## الجهات

| الجهة | ما تستخدمه |
|---|---|
| المركز الحكومي | أوامر الصيانة، والمخزن، والتقارير |
| رئيس الفريق | لوحته، والتقارير، والفنيون، وبدل الموقع، وإدارة المركز، والإعدادات |

## Firebase (بيانات مشتركة ومحمية على الخادم)

عند تعبئة `FIREBASE_CONFIG` داخل `index.html` يعمل التطبيق على **Firebase**:
الدخول بحساب Firebase لكل جهة، و**قواعد الأمان في `firestore.rules`** تمنع أي حساب آخر من الوصول للبيانات.
(نسخة claude.ai لا تستطيع الاتصال بـ Firebase وتبقى على قاعدتها الخاصة.)

1. افتح https://console.firebase.google.com ← **Add project** ← اختر اسماً ← أكمل الإنشاء.
2. **Build ← Firestore Database ← Create database** ← **Production mode** ← أقرب موقع (مثل `me-central2`).
3. **Build ← Authentication ← Get started ← Email/Password ← Enable**.
4. **Authentication ← Settings ← User actions**: ألغِ **Enable create (sign-up)**.
5. **Authentication ← Settings ← Authorized domains**: أضف `aed60907080-crypto.github.io`
6. **⚙ Project settings ← Your apps ← أيقونة الويب `</>`** ← سجّل التطبيق ← انسخ `firebaseConfig`.
7. **Authentication ← Users ← Add user** — حسابان (`authDomain` من الخطوة 6)، وكلمة سر كل منهما ٦ أحرف على الأقل:

| الجهة | البريد |
|---|---|
| المركز الحكومي | `gov@<authDomain>` |
| رئيس الفريق | `chief@<authDomain>` |

8. ضع `firebaseConfig` في `FIREBASE_CONFIG` داخل `index.html`، واستبدل `YOUR-PROJECT.firebaseapp.com` في `firestore.rules` بقيمة `authDomain`.
9. **Firestore Database ← Rules** ← الصق محتوى `firestore.rules` ← **Publish**.

- تغيير كلمة السر: من صفحة **الإعدادات** بعد الدخول بالحساب.
- كلمة سر منسية: احذف الحساب من **Authentication ← Users** وأنشئه من جديد بالبريد نفسه.

## ملاحظات أمنية

- بدون Firebase تُحفظ كلمات السر مُجزَّأة (SHA-256 مع ملح)، والصلاحيات تُطبَّق داخل النظام لا على الخادم.
- مع Firebase تُطبَّق الصلاحيات على الخادم عبر `firestore.rules`.
- الإرسال التلقائي للتقارير يحدث عند فتح النظام بعد نهاية الشهر؛ الصفحة لا تعمل في الخلفية وهي مغلقة.
